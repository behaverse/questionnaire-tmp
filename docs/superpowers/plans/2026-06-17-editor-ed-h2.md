# Editor ED-H2 — Readable Content Labels Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Make the structure tree and canvas item rows show the actual question/message TEXT (with the entity id demoted to a secondary affordance) instead of raw `pr_x@v26.0606` refs.

**Architecture:** One shared pure helper `resolveNodeLabel(model, path, pool, resolved, locale) → { text, id, ref }` that mirrors the existing translation-dot resolution (`pool[ref] ?? resolved[ref]` → `content[locale].text`, with locale fallback). Tree and canvas call it per node and render `text` primary + `id` secondary, falling back to `id` when text is unresolved (offline).

**Tech Stack:** Vite + React 19 + TS + Tailwind, Zustand, vitest + @testing-library/react, Playwright.

## Global Constraints

- Work in `editor/`. All commands from `editor/`.
- **Presentation only** — no model/store/schema/behavior change. Resolution reads `pool`/`resolved` already in the store; it never fetches.
- **Offline fallback:** when no text resolves (Library ref + preview closed, or empty content), show the `id` (without `@version`) as primary — never a blank row. Brand-new empty items show `Untitled item`.
- Keep everything H1 added: node icons, accent selection, numbering, translation dots, kind chips, Required checkbox, UpgradeBadge, ForkButton, delete control, select-on-click.
- Locale = `editingLocale ?? metadata.language` (the same locale the tree's translation dots use).
- **Expected test churn:** tests that assert the old raw ref-with-version label (notably `Canvas.test.tsx`'s `getByText(firstEl.ref)`) change by design — update them to the new resolved/fallback form. Keep all suites green.
- Each task: `npm run typecheck` clean + relevant vitest green. Commit per task. Landing to master is handled by the controller (isolate-cherry-pick), not in these tasks.

```ts
// editor/src/tree/nodeLabel.ts
import type { Questionnaire, EntityBody } from '../model/types'
import { getAtPath, type NodePath } from '../model/path'

type Body = { content?: Record<string, { text?: string }> }

function textFrom(body: Body | null | undefined, locale: string): string | null {
  const c = body?.content
  if (!c) return null
  const pick = c[locale]?.text ?? c.en?.text ?? Object.values(c).map((v) => v?.text).find(Boolean)
  const t = (pick ?? '').trim()
  return t || null
}

/** Human-readable label for a structure node: resolved content text + the bare entity id. */
export function resolveNodeLabel(
  model: Questionnaire,
  path: NodePath,
  pool: Record<string, EntityBody>,
  resolved: Record<string, EntityBody | null>,
  locale: string,
): { text: string | null; id: string | null; ref: string | null } {
  const el = getAtPath(model, path) as Record<string, unknown> | undefined
  if (!el) return { text: null, id: null, ref: null }

  // ref-bearing nodes: message element (el.ref) or item (question.prompt.ref)
  const q = el.question as Record<string, unknown> | undefined
  const ref = (typeof el.ref === 'string' ? el.ref
    : (q?.prompt as { ref?: string } | undefined)?.ref) ?? null
  if (ref) {
    const body = (pool[ref] ?? resolved[ref]) as Body | null | undefined
    return { text: textFrom(body, locale), id: ref.split('@')[0], ref }
  }

  // titled nodes: page / block / section
  const title = typeof el.title === 'string' && el.title.trim() ? el.title.trim() : null
  const id = typeof el.id === 'string' ? el.id : null
  return { text: title, id, ref: null }
}
```

(If `EntityBody` is not exported from `../model/types`, use `Record<string, unknown>` for the pool/resolved value type — match whatever `store.ts` uses.)
