# Editor ED-H4 — Re-token Editor Internals Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Finish the ED-H visual system by re-tokening the ~174 `slate-*` usages remaining in the CRUD-editor internals + dialogs (out of ED-H's chrome-only scope), so the whole editor uses the `ed-*` token palette consistently.

**Architecture:** A purely mechanical, deterministic class-rename sweep applying ONE shared mapping table across the authoring editors (Task 1) and the dialogs/pickers/preview/misc (Task 2), then a verification gate (Task 3). No behavior, structure, or logic change — only Tailwind class strings.

**Tech Stack:** Vite + React 19 + TS + Tailwind, vitest + Playwright.

## Global Constraints

- Work in `editor/`. All commands from `editor/`.
- **Class strings only.** No JSX structure, props, handlers, or logic change. No new components.
- **Preserve semantic status colors** — `amber-*`, `green-*`, `red-*`, `emerald-*` (unsaved dot, staleness badge, translation dots, error/validation messages, danger) stay exactly as they are. Only neutral `slate-*` (and container `bg-white`) get re-tokened.
- **Accessible names / test queries unchanged** (tests query by role/label/text, not class) — so unit + e2e stay green without churn. Run them to confirm.
- Each task: `npm run typecheck` clean + `npm test` green. Commit per task. Landing is the controller's job (isolate-cherry-pick).

## The mapping table (apply verbatim in both Tasks 1 and 2)

```
text-slate-800 | text-slate-700 | text-slate-600   → text-ed-text
text-slate-500 | text-slate-400 | text-slate-300   → text-ed-muted
border-slate-100 | border-slate-200 | border-slate-300 → border-ed-border
bg-slate-50 | bg-slate-100                          → bg-ed-subtle
hover:bg-slate-50 | hover:bg-slate-100              → hover:bg-ed-subtle
bg-slate-200            (selected/active fill)      → bg-ed-accent-soft
bg-slate-800 | bg-slate-700  (dark primary button)  → bg-ed-accent           (keep text-white)
hover:bg-slate-800 | hover:bg-slate-700            → hover:brightness-110
bg-white                (panel/card/dialog surface) → bg-ed-panel
focus:border-slate-* | focus:ring-slate-* | ring-slate-* → focus-visible:ring-2 focus-visible:ring-ed-accent
```

Plus: any `uppercase tracking-wide text-slate-*` micro-label → drop `uppercase tracking-wide`, use `text-ed-muted` (sentence-case, matching the rest of ED-H). Leave non-slate `bg-white` that is clearly NOT a surface (rare) alone if unsure — but editor dialogs/cards are surfaces → `bg-ed-panel`.

**Gate for each sweep task:** after editing its files, `grep -rn "slate-" <its files>` returns nothing, and `grep -rn "ed-text\|ed-muted\|ed-border\|ed-subtle\|ed-accent\|ed-panel" <its files>` shows the replacements.
