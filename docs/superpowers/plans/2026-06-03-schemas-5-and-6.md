# Schemas 5 (Response Data) + 6 (Session Metadata) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create initial `schemas/response/` (Schema 5) and `schemas/session/` (Schema 6) families at CalVer v26.0603. Schema 5 is strict BDM Response trial table adherence (with three documented deviations); Schema 6 is our session metadata schema carrying `scorer_outputs` and the session lifecycle.

**Architecture:** Two new schema directories alongside `schemas/instrument/` and `schemas/questionnaire/`. Both ship JSON Schema + JSON-LD context + examples + CHANGELOG + README. Validator extensions add three new cross-checks (stimulus_id decomposability, response/session consistency, scorer_outputs against Scorer's output_schema).

**Tech Stack:** JSON Schema Draft 2020-12 · Python 3.11+ · `jsonschema` ≥4.20 · `referencing` ≥0.30 · `pytest` ≥8.0.

**Spec:** [docs/superpowers/specs/2026-06-03-schemas-5-and-6-design.md](../specs/2026-06-03-schemas-5-and-6-design.md).

**Pre-condition:** `git status` clean. Current commit: `197dfbf` (OD-17 ratification).

### Task 12: `check_stimulus_id_decomposable`

Add a new cross-check function in `tools/validate_schemas.py`:

```python
def check_stimulus_id_decomposable(schemas_root: Path) -> list[tuple[Path, str, list[str]]]:
    """For each Response example, verify stimulus_id parses into valid entity-id parts."""
    out = []
    valid_prefixes = ("ctx_", "ins_", "pr_", "msg_")
    response_examples = schemas_root / "response" / "examples"
    if not response_examples.is_dir():
        return out
    for q_path in sorted(response_examples.glob("*.json")):
        instance = json.loads(q_path.read_text())
        rows = instance.get("responses", []) if "responses" in instance else [instance]
        errs = []
        for row in rows:
            sid = row.get("stimulus_id", "")
            if not sid:
                continue
            parts = sid.split("+")
            for part in parts:
                if not any(part.startswith(p) for p in valid_prefixes):
                    errs.append(f"STIMULUS_ID_MALFORMED: '{sid}' contains '{part}' with invalid prefix")
        out.append((q_path, "stimulus_id", errs))
    return out
```

### Task 13: `check_scorer_outputs_against_schema`

Add a cross-check that validates each `Session.scorer_outputs[key]` against the corresponding Scorer entity's `output_schema` in `schemas/questionnaire/examples/library_examples/scorers/`.

```python
def check_scorer_outputs_against_schema(schemas_root: Path) -> list[tuple[Path, str, list[str]]]:
    """For each Session example with scorer_outputs, validate each entry against
    the Scorer entity's output_schema."""
    out = []
    # Load known scorers
    scorers_dir = schemas_root / "questionnaire" / "examples" / "library_examples" / "scorers"
    scorers = {}
    if scorers_dir.is_dir():
        for sf in sorted(scorers_dir.glob("*.json")):
            data = json.loads(sf.read_text())
            scorers[data["id"]] = data
    session_examples = schemas_root / "session" / "examples"
    if not session_examples.is_dir():
        return out
    for s_path in sorted(session_examples.glob("*.json")):
        instance = json.loads(s_path.read_text())
        outputs = instance.get("scorer_outputs", {})
        errs = []
        for ref, value in outputs.items():
            sid = ref.split("@")[0]
            scorer = scorers.get(sid)
            if not scorer:
                errs.append(f"UNRESOLVED_SCORER: {ref}")
                continue
            output_schema = scorer.get("output_schema", {})
            try:
                Draft202012Validator(output_schema).validate(value)
            except Exception as e:
                errs.append(f"OUTPUT_VALIDATION_FAILED for {ref}: {str(e)[:100]}")
        out.append((s_path, "scorer_outputs", errs))
    return out
```
