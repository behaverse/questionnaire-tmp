# Schema 2 v26.0602 Implementation Plan (OD-16 Pivot)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land the OD-16 resolution in Schema 2. Add the `Scorer` Library entity (`scr_*`), the `Score` declaration type, the top-level `scores[]` and `lock_show_score_timing` fields. Narrow `Subscale` to a label entity. Add `Prompt.subscales[]`. Remove `ScoringDef`, `InterpretationBand`, the Questionnaire's top-level `subscales[]` and `scoring[]` blocks. Archive v26.0601 under `versions/`.

**Architecture:** Extend `schemas/questionnaire/schema.json` from v26.0601 to v26.0602. The OD-15 entity model (11 reusable entities + page composition) is preserved; only the scoring surface changes. Same Python validator harness, extended with two new `library_examples/` directories and a cross-reference path checker.

**Tech Stack:** JSON Schema Draft 2020-12 · Python 3.11+ · `jsonschema` ≥4.20 · `referencing` ≥0.30 · `pytest` ≥8.0 · JSON Pointer (RFC 6901).

**Spec:** All design decisions are in [docs/superpowers/specs/2026-06-02-schema-2-v26.0602-design.md](../specs/2026-06-02-schema-2-v26.0602-design.md). The spec is the source of truth for entity shapes; this plan adds task ordering, test code, and commit cadence.

**Pre-condition:** `git status` should be clean before starting. The v26.0601 ratification commits (`ad74a5a` and predecessors) and the v26.0602 spec commit (`a86a972`) are already on `master`. Start from there.

```python
def check_score_paths(schemas_root: Path) -> list[tuple[Path, str, list[str]]]:
    """For each questionnaire example, validate every scores[] entry's
    scorer+path against the Scorer entities in library_examples/scorers/.

    Returns a list of (path, kind, errors) tuples.
    """
    out = []
    scorers_dir = schemas_root / "questionnaire" / "examples" / "library_examples" / "scorers"
    scorers = {}
    if scorers_dir.is_dir():
        for sf in sorted(scorers_dir.glob("*.json")):
            data = json.loads(sf.read_text())
            scorers[data["id"]] = data
    examples_dir = schemas_root / "questionnaire" / "examples"
    if not examples_dir.is_dir():
        return out
    for q_path in sorted(examples_dir.glob("*.json")):
        instance = json.loads(q_path.read_text())
        errs = []
        for score in instance.get("scores", []):
            scorer_ref = score.get("scorer", "")
            sid = scorer_ref.split("@")[0] if "@" in scorer_ref else scorer_ref
            sc = scorers.get(sid)
            if sc is None:
                errs.append(f"UNRESOLVED_SCORER: {scorer_ref}")
                continue
            path = score.get("path", "")
            target = _walk_json_pointer(sc.get("output_schema", {}), path)
            if target is None:
                errs.append(f"PATH_NOT_FOUND: {path} in {sid}")
            elif target.get("type") == "object" or target.get("type") == "array":
                errs.append(f"PATH_NOT_LEAF: {path} resolves to {target.get('type')}")
        out.append((q_path, "score_paths", errs))
    return out


def _walk_json_pointer(schema, pointer):
    """Walk a JSON Pointer against a JSON Schema. Returns the leaf schema or None."""
    if not pointer:
        return None
    parts = pointer.split("/")[1:]  # drop leading empty from leading /
    node = schema
    for p in parts:
        # JSON Schema convention: walk via .properties
        props = node.get("properties") if isinstance(node, dict) else None
        if not props or p not in props:
            return None
        node = props[p]
    return node
```
